SA AI Unfiltered Guest List - Static Vercel Page

Deployment steps:
1. Unzip this folder.
2. Upload the folder to GitHub or drag/drop it into Vercel if your plan supports manual deployment.
3. Deploy on Vercel.
4. Use the Vercel URL to generate the final QR code.

No Quicket API key or user token is used in this version.
The page contains only public guest information: title, name, organisation and designation.
